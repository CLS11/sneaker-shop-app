#  Sneaker Shop App

A sleek, responsive, and modern sneaker shopping application built using **Flutter**. This app showcases product displays, smooth UI animations, and essential shopping features for a minimal yet engaging user experience.

---

##  Features

-  Sneaker product catalog
-  Add to Cart
-  Beautiful product details screen
-  Interactive UI & smooth animations
-  Bottom navigation
-  Responsive design for various screen sizes

---

## 🛠️ Tech Stack

- **Flutter** – UI toolkit
- **Dart** – Programming language
- **Provider / setState** – State management 
- **Custom Animations** – For UI transitions
- **Google Fonts** – Stylish typography
- **Asset Management** – Image & data handling
